# selenium-practice

Practice scripts I wrote while learning Selenium WebDriver. Using the-internet.herokuapp.com as a test site since it has all kinds of UI elements to practice on.

## What's here

- `test_login.py` - basic login test
- `test_forms.py` - dropdowns, checkboxes, text inputs
- `test_navigation.py` - browser back/forward/refresh

## Setup

1. Install Python 3
2. Install Chrome and download chromedriver (make sure versions match!)
3. `pip install -r requirements.txt`

## Run

```bash
python tests/test_login.py
python tests/test_forms.py
python tests/test_navigation.py
```
